## Ключевые проектные ограничения (не нарушать ни на одном этапе)

1. **Детерминизм**: все случайности — из seedable PRNG мира; повтор прогона даёт тот же результат.
2. **Скрытые броски**: клиент никогда не получает сырые значения Fortune; только последствия.
3. **Наследование механическое**: игрок не выбирает исход переворота — только готовится к нему.
4. **Канон честен**: искажаются только нарратив и оценки, canonical-цифры неизменны и доступны.
5. **Обратная совместимость**: `politics.enabled=false` ⇒ поведение идентично Rev 3.
