## [Unreleased]

### Добавлено
- **Экран «🗺 Карта»** (`#/map`, ui-client.md §2.11): карта территорий через призму
  знаний цивилизации игрока — сервер хранит полную скрытую карту мира, клиент получает
  интерпретацию области, открытой географами народа (design.md §22.8). Три состояния
  знания (`known`/`dim`/Terra Incognita), проекции (равнопромежуточная/Меркатора/коническая),
  топонимы-лор (народные имена-эпитеты по характеру места), мифы и предания народа на
  неизвестных землях, слухи о смутно ведомых, бюджет посещений за ход из транспортных
  сетей и технологий эпохи со списком экспедиций и честными причинами недоступности.
  Сервер: модуль `poem/mapview.py`, маршрут `GET /api/v1/worlds/{id}/map`
  (`civilization_id`, `projection`); клиент: `MapScreen` (`web/js/screens.js`),
  `api.mapView()`, стили `.map-*`; детерминизм (§4.1) и отсутствие реальных часов
  (§20.4) покрыты тестами `tests/test_map_view.py` (19 тестов). Приём POST-заявок на
  посещение — отдельная задача ядра хода (интерфейс честно сообщает об отсутствии записей).
- **Rev 4 (спецификация): политическая философия** (`design.md` §22, `rules.md` §9bis,
  README «Ключевые особенности» п.9): интеграция «Государя» Макиавелли и «Дао Дэ Цзина»
  Лао-цзы как явных механик — скрытые броски Фортуны (детерминированный PRNG от seed
  мира, клиенту не раскрываются), фракции элит (power/loyalty/grievance/ambition) с
  динамикой страха и любви, интриги и заговоры с **механическим наследованием власти**
  (игрок ставится перед фактом), линия правления либерал↔тиран, постоянство законов →
  decay risk-premium предпринимателей при росте сложности и падении устойчивости
  экономики, ву-вэй (бонус недеяния), равновесный возврат экстремальных агрегатов,
  пустые ниши с убывающим бонусом первым вошедшим, штраф за демонстративную мудрость,
  агентность AI-соперников (рынки сбыта, ниши, influence_field, характер договоров),
  искажение нарративных отчётов (лесть/цензура/self_deception) при неизменном честном
  каноне с метками `canonical/narrative`. Расширенный пайплайн хода (шаги 8a, 13a, 16a,
  17a, 17b, 19a), модели данных, API, тест-план (§22.9) и задачи TASK-070…TASK-077.
  Обратная совместимость: при `politics.enabled=false` движок ведёт себя точно как Rev 3.
- **Аутентификация администратора сервера** (`poem/api.py`, §15 security addendum): все
  изменяющие маршруты (`POST`/`PUT`/`DELETE`/`PATCH`) требуют токен из `POEM_ADMIN_TOKEN`;
  сравнение за постоянное время (`hmac.compare_digest`); ответы `401`/`403`; отдельный
  токен GPU-воркера `POEM_IMAGE_WORKER_TOKEN`; публичные только `GET`. Генератор токенов
  `generate_admin_token()`. Тесты — `tests/test_admin_auth.py`. Документация —
  `guide_server.md` §4.4a, README «HTTP API».
- **Опциональная LLM-генерация игровых текстов** (`poem/llm.py`): литературные секции
  отчёта правителя (§13.22) могут переписываться LLM в стиле хроник мира. Выключено по
  умолчанию (`POEM_LLM_ENABLED=1` — включение); транспорты: OpenAI-совместимый HTTP,
  локальный CLI-мост; детерминированные промпты (без wall-clock), кэш по `sha256(prompt)`,
  гарантированный fallback на шаблоны при любом сбое. Зависимостей не добавлено (только
  stdlib). Тесты — `tests/test_llm_texts.py`.
- Файл `LICENSE` (MIT) и этот `CHANGELOG.md`.
- `.gitignore` для артефактов Python (`__pycache__/`, `*.pyc`, `*.log`); отслеживаемые
  `.pyc` удалены из индекса git.

### Исправлено
- `NameError: applied_set` в `run_turn` (`poem/turn.py`): переменная статуса применённых
  ревизий не объявлялась — любой ход с применёнными ревизиями падал (11 тестов).
- Сигнатура вспомогательного дубля `apply_once` в `tests/test_failed_revision_status.py`
  (`TypeError` из-за нового kwarg `turn_id_of_application`).
- «Слово о мире» терялось в отчёте правителя, если война завершилась мирным договором на
  текущем ходу (`poem/turn.py`, `poem/chronicle_report.py`): стороны завершённых войн
  собираются до цикла тиков; договор попадает в секцию дипломатии отчёта; шаблоны стихов
  поддерживают подстановку имени противника (`{enemy}`/`{civ}`).
- Синхронизация README с кодом: число модулей ядра, структура репозитория (16 файлов /
  172 теста), описание новых возможностей.
